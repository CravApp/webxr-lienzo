# webxr-lienzo

Spike previo al SRS: un lienzo WebXR que se pinta con los mandos del Quest 3 como pinceles, y passthrough en todo lo demás.

Esta página es el primer corte. Abre una sesión `immersive-ar` y deja un cubo de 30 cm sobre el passthrough. En el escritorio se ve el mismo cubo, sin sesión AR.

https://cravapp.github.io/webxr-lienzo/

## Controles

- **Gatillo:** enciende o apaga el giro automático.
- **Thumbstick:** rota el cubo (izquierda/derecha en el eje Y, arriba/abajo en el eje X).
- **Grip:** cerca del cubo o apuntándolo, lo agarra y lo gira con el mando.
